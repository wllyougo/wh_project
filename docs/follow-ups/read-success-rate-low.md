# 실제 판매 페이지의 자동 읽기 성공률이 낮다

- 증상: 실제 서비스(imgbb, SerpApi, 사내 게이트웨이)로 젤리 사진 2장을 시험했을 때 후보 6개 중 5개를 읽지 못했다.
- 근거:
  - 이미지 식별은 두 사진 모두 맞는 제품군이 나왔다(망고젤리는 다이소몰이 첫 후보).
  - 다이소몰 페이지는 서버 요청으로는 원재료 글자가 HTML에 없다(스크립트로 그려짐).
  - 네이버 블로그는 200이지만 2.8KB짜리 껍데기(본문은 별도 프레임)이고, 쿠팡은 403(봇 차단)이다. 앞서 curl이 000을 낸 것은 Windows curl의 인증서 폐기 확인 오류이고 사내망 차단이 아니다. 서버가 쓰는 Node fetch로는 접속된다.
  - 컬리는 200이고 원재료 글자가 HTML에 있어 읽힐 가능성이 있다.
  - 읽기에 성공한 것은 Shopify 기반 몰의 BT21 젤리 페이지 하나였고, 알레르기 표시란은 없었다.
- 추정 원인: 판매 페이지가 스크립트 렌더링이거나 봇을 막는다. 후보에 후기 블로그가 섞여 있다.
- 다음 단계: 후보에서 블로그를 거르고, 스크립트 렌더링 페이지는 브라우저 렌더링이나 사이트별 방법을 검토한다. 사내망이 아닌 환경에서 접속률을 다시 잰다.
- 남은 알림: 스펙의 "읽기 실패 시 원문 링크" 임시 동작이 현재 대부분의 결과에서 쓰인다.
